# Dedo Certo

Curso de digitação para o teclado brasileiro ABNT2, em 24 níveis.

Abra `index.html` no navegador (computador ou tablet com teclado). Não precisa instalar nada.

- Cada nível explica quais dedos usar e dá uma técnica para ganhar velocidade.
- O próximo nível é liberado quando você atinge a meta de palavras por minuto (PPM) e de precisão.
- O teclado na tela mostra a próxima tecla, o dedo certo e o Shift a usar, incluindo as teclas mortas de acento (´ ` ~ ^).
- O progresso fica salvo no próprio navegador.
